Sin plan en ejecución Cuando Claude Code registre un plan, sus pasos aparecen abajo como tarjetas y se mueven solos entre columnas. Mientras tanto el tablero es tuyo: añade las tarjetas que quieras.
ACTIVIDAD
Ningún archivo abierto Elige un proyecto en el explorador y abre un archivo del árbol. Se guarda con ⌘S, y si Claude Code lo cambia por su cuenta se recarga solo.
Sin sesión abierta Abre un proyecto del carril izquierdo: se arranca Claude Code dentro de esa carpeta y lo usas aquí mismo. Para comandos sueltos está la terminal del dock, a la derecha.
Sin proyecto analizado Elige una carpeta arriba: el panel lee el código, dibuja una constelación con sus funciones y te dice dónde se usa cada una.
Sin nada que enseñar Elige un proyecto arriba y el panel lo sirve en un puerto local, o escribe la URL del servidor que ya tengas levantado.
